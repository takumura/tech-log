# 📌 定義
> [!NOTE] Definition
> 本Vaultにおけるファイル名やNote記法など、Noteの作成に関するルールを定義します。

## 📌 1. ファイル名

- テンプレートファイルには、ファイル名の先頭に`📋`を付けます
- Hub Noteには、ファイル名の先頭に`🗺️`を付けます。
- Troubleshooting Noteには、ファイル名の先頭に`🛠️`を付けます。

## 📌 2. Frontmatter

Frontmatterに定義するプロパティは以下とします。

- created (optional): Noteの作成日を設定します。
- updated (optional): Noteを更新した日付を設定します。Note編集時に随時更新します。[[📋insert updated date on frontmatter|Templaterのテンプレート]]作成済みです。
- type (mandatory): `evergreen` または `snapshot`。詳細は[[Note分類ルール]]を参照してください。
- category (mandatory): `atomic`, `journal`, `todo` などを使用します。詳細は[[Note分類ルール]]を参照してください。
- tags (mandatory): `rule`, `idea`, `term` などを使用します。詳細は[[Note分類ルール]]を参照してください。

### type、category、tagsのルール

- アルファベット小文字を使用します。
- 空白は使用しない。空白の代わりに`-`を使用します。

## 📌 3. Note本文

### 文末表現のルール

- 文末はです・ます調で統一してください（だ・である調は使用しない）。
	- 過去形（「〜なった」「〜掛かった」等）も、です・ます調（〜ました・〜になりました）で統一します。
	- `10_Objective`はです・ます調にする必要性が低いため、例外とします。
	- `22_WebClips`は原文を保存するため、例外とします。 
	- tagに`manga`、`drama`、`movie`を持つものも、同様に例外とします。
- callout内の定義文もです・ます調に統一します。
- 体言止め、形容詞止めは許容します。
- コード句内の文章は対象外とします。

### 見出しのルール

- 見出しはLevel4（H1～H4）までとし、あまり階層が深くならないようにします。階層が深くなる場合はNoteの分割を検討してください。
- 見出し（H1～H4）の次行がcallout以外の場合は必ず改行します。
	- 22_WebClipsのデータは外部サイトからのデータであるためルール対象外とします。
-  **アイコンの使用**: 見出しH1とH2には、内容に応じて以下のアイコンを付与します：
	- `🎯`: 目標
	- `📌`: 定義
	- `🗺️`: Hub
	- `📈`: 進捗 / マイルストーン
	- `💡`: 着想 / 気付き / 振り返り
	- `🏃`: 活動
	- `🔍`: 概要
	- `🧩`: 詳細
	- `💎`: 要点
	- `📝`: 記録
	- `🚀`: Todo / タスク
	- `🛠️`: 設定
	- `❓`: 問題
	- `✅`: 解決策
	- `🎨`: テーマ / パレット
	- `🔗`: 参考資料 / 関連リンク

### リストのルール

- サブリストには空白2個ではなく tab1個を使用します。

### 括弧のルール

- 丸括弧`（）`は日本語の文章では**全角**を、英語などの半角文字で表現する文章では**半角**を使用します。

## 📌 4. その他

- テンプレート化可能なものは、随時`02_Assets/Templates/Templater`フォルダ以下にテンプレートを作成し、フォーマットを統一します。
- mindmap pluginを利用するNoteには `mindmap` タグを設定します。
